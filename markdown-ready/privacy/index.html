Markdown Ready Privacy PolicyMarkdown Ready 개인정보처리방침

Last updated: June 18, 2026최종 갱신: 2026년 6월 18일

Markdown Ready is a macOS document conversion app by HydRoMo. It converts PDFs, scanned pages, and document images into Markdown and optional JSON files using local processing on your Mac. Markdown Ready는 HydRoMo의 macOS 문서 변환 앱입니다. PDF, 스캔 문서, 문서 이미지를 Mac에서 로컬 처리하여 Markdown과 선택적 JSON 파일로 변환합니다.

Data Collection데이터 수집

Markdown Ready does not collect data from the app. The app does not include account login, advertising, tracking, analytics, or a cloud OCR API for document conversion. Markdown Ready는 앱에서 데이터를 수집하지 않습니다. 계정 로그인, 광고, 추적, 분석, 문서 변환용 클라우드 OCR API가 포함되어 있지 않습니다.

Document Processing문서 처리

Documents selected in Markdown Ready are processed locally on your Mac. Document contents are not uploaded by Markdown Ready for OCR conversion. Output files are written to the output folder you choose. Markdown Ready에서 선택한 문서는 Mac에서 로컬로 처리됩니다. OCR 변환을 위해 문서 내용을 업로드하지 않습니다. 출력 파일은 직접 고른 출력 폴더에 기록됩니다.

Local Storage로컬 저장

Markdown Ready may store local settings on your Mac, including selected input/output paths, security-scoped bookmarks granted through macOS file and folder pickers, output preferences, and local conversion state. These values are stored locally for app functionality. Markdown Ready는 선택한 입력·출력 경로, macOS 파일·폴더 선택기로 부여받은 보안 범위 북마크, 출력 설정, 로컬 변환 상태 등 앱 설정을 Mac에 저장할 수 있습니다. 이 값은 앱 기능을 위해 로컬에만 저장됩니다.

Folder Access폴더 접근

Markdown Ready accesses files and folders only through permissions you grant using macOS file and folder pickers. You can change selected folders in the app. Markdown Ready는 macOS 파일·폴더 선택기로 부여한 권한을 통해서만 파일과 폴더에 접근합니다. 선택한 폴더는 앱에서 언제든 바꿀 수 있습니다.

Support지원

If you contact support, you may choose to provide information such as your email address, app version, macOS version, Mac model, screenshots, logs, or sample files. Support information is used to respond to your request. Do not send sensitive documents unless you intentionally choose to share them. 지원에 문의하면 이메일 주소, 앱 버전, macOS 버전, Mac 모델, 스크린샷, 로그, 샘플 파일 등을 선택적으로 제공할 수 있습니다. 지원 정보는 요청에 응답하는 용도로만 사용됩니다. 민감한 문서는 일부러 공유하기로 결정한 경우가 아니면 보내지 마세요.

Third-Party Components서드파티 구성 요소

Markdown Ready includes open source software and local OCR model components. License notices are available in the app under About / Open Source Licenses. Markdown Ready는 오픈소스 소프트웨어와 로컬 OCR 모델 구성 요소를 포함합니다. 라이선스 고지는 앱의 About / Open Source Licenses에서 볼 수 있습니다.

Changes변경

This policy may be updated as Markdown Ready changes. If app data practices change, App Store privacy information and this policy should be updated accordingly. 이 방침은 Markdown Ready가 변경됨에 따라 갱신될 수 있습니다. 앱의 데이터 관행이 바뀌면 App Store 개인정보 정보와 이 방침도 그에 맞게 갱신됩니다.
