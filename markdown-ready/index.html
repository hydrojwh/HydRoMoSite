Local Processing로컬 처리

Your documents stay on your Mac문서는 당신의 Mac에 머무릅니다

Your documents are selected through macOS file and folder pickers and processed locally. Markdown Ready does not upload document contents to a cloud OCR API. The output is written to the folder you choose. 문서는 macOS 파일·폴더 선택기로 선택되고 로컬에서 처리됩니다. Markdown Ready는 문서 내용을 클라우드 OCR API로 업로드하지 않습니다. 결과물은 직접 고른 폴더에 기록됩니다.

One-Time Folder Batches일회성 폴더 배치

The batch is non-recursive: subfolders are not traversed, and Markdown Ready does not watch or poll the folder for later changes. 폴더를 고르고 Start를 누르면 그 폴더 바로 안의 지원 파일을 한 번 처리합니다. 배치는 비재귀 방식이라 하위 폴더는 들어가지 않고, 이후 변화를 지켜보거나 폴링하지도 않습니다.

How It Works작동 방식

From source file to reviewable output원본 파일에서 검토 가능한 결과까지

  1. Select a PDF, document image, or folder.PDF, 문서 이미지 또는 폴더를 선택합니다.
  2. Choose where Markdown Ready should save converted files.변환된 파일을 저장할 위치를 정합니다.
  3. Pick Markdown and optional JSON output.Markdown과 선택적 JSON 출력을 고릅니다.
  4. Turn Tables on when structure matters and choose how Existing output is handled.구조가 중요하면 Tables를 켜고, 기존 출력 처리 방식(Existing)을 정합니다.
  5. Press Start. A folder input runs once over supported top-level files only.Start를 누릅니다. 폴더 입력은 지원되는 최상위 파일에 대해 한 번만 실행됩니다.
  6. Use Output to review the saved files before using them downstream.Output에서 저장된 파일을 확인한 뒤 활용하세요.

Important Notes알아두세요

Local OCR is useful, but still needs review로컬 OCR은 유용하지만, 검토는 여전히 필요합니다

Performance and power성능과 전원

Large PDFs and folder batches can use sustained CPU/GPU and unified memory on Apple Silicon. For long conversions, keep your Mac connected to power.큰 PDF와 폴더 배치는 Apple Silicon의 CPU/GPU와 통합 메모리를 지속적으로 사용할 수 있습니다. 긴 변환에는 Mac을 전원에 연결해 두세요.

Accuracy정확도

OCR is not perfect. Complex tables, formulas, handwriting, historical scans, screenshots, tiny text, and low-quality source images can produce mistakes.OCR은 완벽하지 않습니다. 복잡한 표, 수식, 필기, 오래된 스캔본, 스크린샷, 작은 글씨, 품질이 낮은 원본 이미지는 오류를 만들 수 있습니다.

FAQ

Common questions자주 묻는 질문

Does Markdown Ready upload my documents?Markdown Ready는 문서를 업로드하나요?

No. Markdown Ready processes selected documents locally on your Mac and writes output to the folder you choose. No cloud OCR API is required for model loading or conversion.아니요. 선택한 문서는 Mac에서 로컬로 처리되고 결과는 직접 고른 폴더에 기록됩니다. 모델 로딩이나 변환에 클라우드 OCR API가 필요하지 않습니다.

Is the output always perfect?출력은 항상 완벽한가요?

No OCR system is perfect. Markdown Ready is designed to make documents easier to inspect and reuse, but important sections should be reviewed before you rely on the output.완벽한 OCR 시스템은 없습니다. Markdown Ready는 문서를 검사하고 재사용하기 쉽게 만들지만, 중요한 부분은 결과를 신뢰하기 전에 검토해야 합니다.

How does folder input work?폴더 입력은 어떻게 동작하나요?

Choose a folder under Input and press Start. Markdown Ready processes supported files directly inside that folder once. It does not recurse into subfolders or watch or poll for later changes.Input에서 폴더를 고르고 Start를 누르면, 그 폴더 바로 안의 지원 파일을 한 번 처리합니다. 하위 폴더 재귀나 이후 변화 감시·폴링은 하지 않습니다.

Why not upload the PDF directly to an AI chat?PDF를 AI 챗에 직접 올리면 안 되나요?

Direct chat is ideal for quick questions. Markdown Ready is for local processing and durable Markdown/JSON that you can inspect, archive, and reuse across tools.빠른 질문에는 직접 챗이 좋습니다. Markdown Ready는 로컬 처리와, 검사·보관·도구 간 재사용이 가능한 안정적인 Markdown/JSON을 위한 도구입니다.

Does it bypass copyright restrictions?저작권 제한을 우회하나요?

No. Process only documents you are authorized to use and follow applicable copyright and other laws.아니요. 사용 권한이 있는 문서만 처리하고, 관련 저작권 및 기타 법률을 준수해 주세요.
