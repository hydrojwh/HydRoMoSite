Markdown Ready SupportMarkdown Ready 지원

Markdown Ready is a private, on-device document compiler for macOS. It converts PDFs, scanned pages, and document images into durable Markdown and optional JSON files that you can inspect, edit, archive, and reuse. Markdown Ready는 macOS용 온디바이스 문서 컴파일러입니다. PDF, 스캔 문서, 문서 이미지를 검사·편집·보관·재사용할 수 있는 안정적인 Markdown과 선택적 JSON 파일로 변환합니다.

Why Markdown Ready?왜 Markdown Ready인가?

Direct PDF chat and Markdown Ready solve different jobs. Direct chat is ideal for a quick question or summary. Markdown Ready is for converting once, keeping the result, and reusing the same local document artifact across services and tools. PDF 직접 챗과 Markdown Ready는 다른 일을 합니다. 빠른 질문이나 요약에는 직접 챗이 맞습니다. Markdown Ready는 한 번 변환해 결과를 남기고, 같은 로컬 문서 산출물을 여러 서비스와 도구에서 재사용하기 위한 도구입니다.

Quick Start빠른 시작

  1. Open Markdown Ready from the menu bar.메뉴 막대에서 Markdown Ready를 엽니다.
  2. Under Engine, choose GLM-OCR or PaddleOCR-VL.Engine에서 GLM-OCR 또는 PaddleOCR-VL을 고릅니다.
  3. Under Input, select a PDF, JPG/JPEG, PNG, or folder. You can also drag supported files into the menu-bar window. Use Save To for the destination.Input에서 PDF, JPG/JPEG, PNG 또는 폴더를 선택합니다. 지원 파일을 메뉴 막대 창에 끌어다 놓아도 됩니다. 저장 위치는 Save To로 정합니다.
  4. Choose Markdown and optional JSON, turn Tables on if needed, and set Existing behavior.Markdown과 선택적 JSON을 고르고, 필요하면 Tables를 켜고, Existing 동작을 정합니다.
  5. Press Start; use Stop to cancel an active conversion.Start를 누릅니다. 진행 중인 변환은 Stop으로 취소할 수 있습니다.
  6. Use Output to review generated files.Output에서 생성된 파일을 확인합니다.
  7. About shows product and license information; Quit closes the app.About에서 제품·라이선스 정보를 볼 수 있고, Quit으로 앱을 종료합니다.

One-Time Folder Batches일회성 폴더 배치

Choose an input folder and a Save To folder, then press Start. Markdown Ready enumerates supported files directly inside the input folder and processes that flat list once. 입력 폴더와 Save To 폴더를 고르고 Start를 누르면, Markdown Ready가 입력 폴더 바로 안의 지원 파일을 모아 그 목록을 한 번 처리합니다.

  • Subfolders are not traversed.하위 폴더는 탐색하지 않습니다.
  • The app does not watch or poll the folder after the run starts or completes.실행 시작 후나 완료 후에 폴더를 지켜보거나 폴링하지 않습니다.
  • Use Existing to choose whether matching output is skipped or overwritten.Existing에서 해당 출력을 건너뛸지 덮어쓸지 정할 수 있습니다.

Performance And Power성능과 전원

Markdown Ready runs local OCR on your Mac. The supported target is an Apple Silicon Mac with 16 GB unified memory or more; 8 GB Macs are not currently validated or supported for the bundled vision-language models. Large PDFs, image-heavy documents, and folder batches can use sustained CPU/GPU and unified memory. For long conversions, connect your Mac to power and avoid closing the lid. Markdown Ready는 Mac에서 로컬 OCR을 돌립니다. 지원 대상은 통합 메모리 16GB 이상의 Apple Silicon Mac이며, 8GB Mac은 내장 비전-언어 모델에 대해 검증·지원되지 않습니다. 큰 PDF, 이미지가 많은 문서, 폴더 배치는 CPU/GPU와 통합 메모리를 지속적으로 사용할 수 있습니다. 긴 변환에는 Mac을 전원에 연결하고 덮개를 닫지 마세요.

Accuracy And Review정확도와 검토

OCR output can contain mistakes. Complex tables, equations, handwriting, poor scans, screenshots, rotated pages, and tiny text need review. Markdown Ready prepares documents for reuse; it does not verify facts or replace human judgment. OCR 결과에는 오류가 있을 수 있습니다. 복잡한 표, 수식, 필기, 품질 낮은 스캔본, 스크린샷, 회전된 페이지, 작은 글씨는 검토가 필요합니다. Markdown Ready는 재사용을 위한 문서를 준비할 뿐, 사실 검증이나 사람의 판단을 대체하지 않습니다.

Privacy개인정보

The app processes selected documents locally and does not upload document contents to a cloud OCR API. Settings, selected folder access bookmarks, and local conversion history are stored on your Mac. Review the 앱은 선택한 문서를 로컬로 처리하며 문서 내용을 클라우드 OCR API로 업로드하지 않습니다. 설정, 선택한 폴더 접근 북마크, 로컬 변환 기록은 Mac에 저장됩니다. 자세한 내용은 Markdown Ready Privacy PolicyMarkdown Ready 개인정보처리방침 for details. 을 확인해 주세요.

Troubleshooting문제 해결

The app cannot access a folder after relaunch재실행 후 폴더에 접근하지 못해요

Choose the input/output folder again from the app so macOS can refresh the user-selected folder permission.앱에서 입력·출력 폴더를 다시 선택해 macOS의 사용자 지정 폴더 권한을 갱신해 주세요.

Conversion is slow변환이 느려요

Large documents can take time because OCR runs locally. Try a smaller test file first, keep the Mac connected to power, and avoid running other heavy workloads at the same time.OCR이 로컬에서 돌기 때문에 큰 문서는 시간이 걸릴 수 있습니다. 작은 테스트 파일로 먼저 확인하고, Mac을 전원에 연결하며, 무거운 작업을 함께 돌리지 마세요.

Output is missing a table or formula출력에 표나 수식이 빠졌어요

Turn Tables on, convert again, and review the output. Very complex tables and formulas may still need manual correction.Tables를 켜고 다시 변환한 뒤 결과를 확인하세요. 매우 복잡한 표와 수식은 여전히 수동 수정이 필요할 수 있습니다.

I do not see a new file in the output folder출력 폴더에 새 파일이 없어요

Confirm that an output folder is selected, the source file type is supported, and the app has permission to access both folders.출력 폴더가 선택돼 있는지, 원본 파일 형식이 지원되는지, 앱이 두 폴더 모두에 접근 권한을 가지고 있는지 확인해 주세요.

Questions And Answers질문과 답변

Why not upload the PDF directly to an AI chat?PDF를 AI 챗에 직접 올리면 안 되나요?

That is often the best choice for a quick question or summary. Use Markdown Ready when you want local processing, a durable Markdown/JSON artifact, a repeatable batch workflow, or output that can move between different services and local tools.빠른 질문이나 요약이라면 그게 최선일 때가 많습니다. 로컬 처리, 남는 Markdown/JSON 산출물, 반복 가능한 배치 워크플로, 또는 서비스와 로컬 도구 사이를 옮겨 다니는 출력이 필요할 때 Markdown Ready를 쓰세요.

What happens when one page cannot be converted reliably?한 페이지를 안정적으로 변환하지 못하면 어떻게 되나요?

Page-local OCR problems normally do not discard the rest of the PDF. Markdown Ready continues, marks the affected page in the output, and writes a page issue report. Model, file-access, cancellation, and output-transaction failures still stop safely.페이지 단위 OCR 문제가 나머지 PDF를 날리지는 않습니다. Markdown Ready는 계속 진행하고, 해당 페이지를 출력에 표시하며, 페이지 이슈 리포트를 남깁니다. 모델·파일 접근·취소·출력 트랜잭션 실패는 안전하게 정지됩니다.

Can a long conversion resume?긴 변환을 이어서 할 수 있나요?

PDFs use ten-page processing chunks. Clean completed chunks are checkpointed during an interrupted conversion and can be reused when the source and conversion settings still match. Chunks with warnings or incomplete output are processed again.PDF는 10페이지 처리 청크를 사용합니다. 중단된 변환에서 깨끗하게 완료된 청크는 체크포인트로 남고, 원본과 설정이 같으면 재사용할 수 있습니다. 경고가 있거나 불완전한 청크는 다시 처리됩니다.

Why can the first conversion take longer?첫 변환이 오래 걸리는 이유는?

The selected local OCR model must load before page processing begins. The app shows model-loading and page progress, and later conversions with the same engine may start sooner while the model remains available. Timing varies by Mac, page count, page layout, and engine, so a fixed minutes-per-document estimate would be misleading.페이지 처리 전에 선택한 로컬 OCR 모델을 먼저 불러와야 합니다. 앱은 모델 로딩과 페이지 진행률을 표시하고, 모델이 남아 있는 동안 같은 엔진의 이후 변환은 더 빨리 시작될 수 있습니다. 소요 시간은 Mac·페이지 수·레이아웃·엔진에 따라 달라져 문서당 몇 분 같은 고정 추정은 오히려 오해를 줍니다.

Does Markdown Ready support an 8 GB Mac?8GB Mac도 지원하나요?

Not as a supported release configuration. Use an Apple Silicon Mac with 16 GB unified memory or more. The bundled vision-language models can put significant pressure on an 8 GB system, and that configuration has not completed the release validation gate.정식 지원 구성이 아닙니다. 통합 메모리 16GB 이상의 Apple Silicon Mac을 사용해 주세요. 내장 비전-언어 모델은 8GB 시스템에 상당한 부하를 줄 수 있고, 해당 구성은 출시 검증을 통과하지 않았습니다.

Is Markdown Ready more accurate than a cloud AI?Markdown Ready가 클라우드 AI보다 정확한가요?

They serve different purposes, and no general accuracy advantage is claimed. Cloud AI can be excellent at understanding and explanation. Markdown Ready focuses on source-grounded, inspectable document conversion. OCR remains best-effort, especially for dense tables, formulas, handwriting, and poor scans.둘은 용도가 다르고, 일반적인 정확도 우위를 주장하지 않습니다. 클라우드 AI는 이해와 설명에 뛰어날 수 있습니다. Markdown Ready는 원본에 근거한, 검사 가능한 문서 변환에 집중합니다. OCR은 특히 빽빽한 표, 수식, 필기, 품질 낮은 스캔에서 최선을 다하는 수준입니다.

Does Markdown Ready upload documents or require an account?문서를 업로드하거나 계정이 필요한가요?

No. The app uses bundled local OCR models, does not require an account, and does not upload document contents to a cloud OCR API.아니요. 내장 로컬 OCR 모델을 쓰고, 계정이 필요 없으며, 문서 내용을 클라우드 OCR API로 업로드하지 않습니다.

Does Markdown Ready bypass copyright restrictions?저작권 제한을 우회하나요?

No. Markdown Ready is a local file-conversion tool, not a rights-clearing service. Process only documents you are authorized to use and follow applicable copyright and other laws.아니요. Markdown Ready는 로컬 파일 변환 도구일 뿐 권리를 해결해 주는 서비스가 아닙니다. 사용 권한이 있는 문서만 처리하고 관련 저작권 및 기타 법률을 준수해 주세요.

What is the main tradeoff?가장 큰 트레이드오프는?

Local OCR adds a preprocessing step, takes time, and can use sustained Mac resources. In return, you keep an inspectable output file that is independent of any one chat or cloud service.로컬 OCR은 전처리 단계가 생기고, 시간이 걸리며, Mac 자원을 지속적으로 쓸 수 있습니다. 그 대가로 어떤 챗·클라우드 서비스에도 의존하지 않는, 검사 가능한 출력 파일을 갖게 됩니다.
